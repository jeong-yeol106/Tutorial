# GradePlan - 대학생 맞춤형 성적 관리 및 학점 예측 프로그램

대학생이 수강 과목의 성적과 이수 학점을 입력하면 학기 평균 평점 및 누적 평점을 자동으로 계산하고, 목표 평점을 달성하는 데 필요한 성적을 역산하며 과목별 예상 성적을 비교할 수 있는 시뮬레이션 웹 애플리케이션입니다.

## 1. 주요 기능
1. **과목별 성적 등록 및 관리**
   - 학년도/학기별 과목명, 이수 학점(1~4학점), 성적 등급(A+ ~ F, P/F) 입력·수정·삭제
   - 동일 학기 내 과목명 중복 등록 검사 및 방지
   - SQLite 기반 로컬 데이터베이스 영구 저장 및 자동 불러오기
2. **학기별 평균 평점 및 전체 누적 평점 자동 산출**
   - 4.5 만점 체계 기준 평점 및 가중 점수 자동 산출
   - Pass/Fail(P/F) 과목 자동 예외 처리
   - 학기별 이수 학점 및 전체 누적 평점 실시간 요약
3. **목표 학점 역산기**
   - 기존 누적 평점/학점과 목표 평점을 기반으로 이번 학기 필요 평균 평점 자동 역산
   - 4.5 초과 시 "현재 조건에서 달성 어려움", 0 이하 시 "이미 달성 가능" 안내
4. **성적 시뮬레이터 및 시나리오 비교**
   - 이번 학기 과목별 등급을 동적으로 변경하며 학기 및 누적 평점 변화 실시간 비교
   - 최상/상향/유지 등 주요 시나리오별 목표 달성 여부 자동 분석
5. **학기별 성적 추이 그래프**
   - Matplotlib을 이용한 학기별 평균 평점 및 누적 평점 변화 꺾은선 그래프 제공

## 2. 기술 스택
- **언어**: Python 3.11+
- **웹 프레임워크**: Streamlit
- **데이터 분석 및 시각화**: Pandas, Matplotlib
- **데이터베이스**: SQLite3
- **패키지 및 환경 관리**: uv
- **테스트**: pytest

## 3. 설치 및 실행 방법

### 환경 동기화 및 의존성 설치
```bash
uv sync
```

### 웹 애플리케이션 실행
```bash
uv run streamlit run app.py
```

### 테스트 실행
```bash
uv run pytest
```
